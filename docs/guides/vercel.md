# Using your frii.site domain with Vercel
 
1. Log into your frii.site account
2. Head over to https://www.frii.site/account/verify/vercel

![Vercel verification page](/vercel.png)

3. Input your verification code into the input field
4. Press Join queue

It is possible that there are other people in the queue. Each user has **45 seconds to verify their domain** before the next person in queue overtakes their seat.
